Sanat Relay Desktop Agent

Sanat Relay lets an AI assistant work with the development projects you approve on your Windows computer. Instead of repeatedly copying source files and error logs into a chat, you can connect selected project files and development tools through a permission-controlled bridge.

What is Sanat Relay?

An AI assistant that can work with your development projects.

Sanat Relay Desktop Agent (SRDA) is a Windows companion application being developed by Sanat Utility Studio. It provides a controlled connection between an AI assistant, such as ChatGPT, and tools available on a developer's own computer.

It uses the Model Context Protocol (MCP), which lets an AI assistant request specific tool actions. With an authorized connection, it can inspect approved project files, investigate errors, run supported builds and tests, or review Git changes without manually copying each file and log into a chat.

It is not a general-purpose remote desktop. The computer owner chooses accessible project folders and tool permissions. A healthy local tunnel test does not by itself establish a verified ChatGPT connection or unrestricted access to the computer.

What it can do

From reading code to checking the build.

Available functions depend on the approved workspace, the connected tools and the permissions granted by the computer owner.

Select project folders

Choose the application or website directories the assistant is allowed to access, rather than exposing unrelated files.

Inspect source code

Locate relevant files, review code and investigate errors in authorized workspaces.

Make controlled changes

Apply authorized source edits with revision checks and recoverable backups where supported.

Run builds and tests

Execute supported project checks, analyze failures and review logs and exit status.

Review Git changes

Check repository status and diffs; commits and pushes require the relevant permissions.

Manage tool access

Enable only the required project tools and permissions. Local connectivity alone does not authorize sensitive actions.

How it works

Four steps from connection to useful work.

Sanat Relay runs locally on Windows. The AI assistant can use supported development tools only through the configured connection and the permissions you provide.

01

Start Sanat Relay

Open the Windows application and check its local connection status.

02

Choose what to share

Approve project folders and the tools needed for the current task.

03

Connect the assistant

Configure and verify the supported MCP connection. A green local tunnel alone is not proof of an active ChatGPT connection.

04

Request and review

Ask for a development task, examine the results and approve sensitive operations when required.

Example workflow

Fixing a failed website build

Suppose a Jekyll website fails to build. With its project folder approved and suitable tools enabled, the assistant could inspect the configuration, identify an error in the build output, suggest an adjustment and rerun validation.

This is an illustrative use case, not a claim that the tool can repair every project automatically. The developer remains responsible for reviewing changes.

Who it is for

Independent developers and hands-on projects.

Sanat Relay is designed for developers maintaining personal applications and websites, experimenting with local AI tools or handling repeat development tasks on Windows.

It aims to reduce repetitive copying between chat windows and development tools while keeping workspace boundaries and the owner's decisions visible.
