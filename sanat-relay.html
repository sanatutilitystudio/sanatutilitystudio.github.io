What is Sanat Relay?

Your AI chat, connected to your development tools.

Sanat Relay Desktop Agent (SRDA) is a Windows application that gives a connected AI assistant access to development tools in project folders you approve. It uses MCP (Model Context Protocol) to let the assistant request specific actions on your PC, instead of making you copy files and build errors into chat.

Connect approved projects

Choose which app or website folders the assistant is allowed to work with.

Read and search code

Ask questions about project files, find errors and inspect source code.

Make controlled edits

Allow the assistant to update approved files with checks and backups where supported.

Build and test

Run supported Windows-based build jobs, analyses and automated tests, then view results in chat.

Work with Git

Review changes and, when explicitly authorized, commit or push updates.

Set tool permissions

Control which folders and operations are available. Sensitive actions require the appropriate permissions.

How it works

Connect. Ask. Build. Check.

SRDA runs on your Windows PC, where your files and developer tools are installed. Once the AI client is connected and you have allowed access, you can request real development tasks through chat.

01 · Start SRDA

Open the Windows companion and check its local connection status.

02 · Approve project access

Select project folders and the tools you want to make available.

03 · Connect ChatGPT

Configure the MCP connection and verify that the assistant can see the permitted tools.

04 · Give a task

Request a build, code review or test. Check the output and authorize changes where needed.

Work from anywhere?

Ask from your phone. Run on Windows.

Remote development is one of SRDA's intended workflows. With a supported AI client and an active connection to your Windows PC, you could send a request from your phone while the computer runs the tools. Mobile-client support must be verified for each setup.

Build through an AI chat

Imagine asking: “Check why my Android app build failed and run the tests again.” SRDA can help a connected assistant work with approved local build tools, rather than just suggest commands.

Test with your Android device

Actual app builds and automated tests run on the Windows PC. Physical-device testing needs the Android toolchain and a reachable phone or emulator; it is not automatically provided by SRDA.

ChatGPT connection is the current focus. Claude and other MCP-compatible clients may require separate setup and testing. A healthy local tunnel alone does not prove that mobile access, a Claude connection or physical-device testing is working.
