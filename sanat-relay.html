What it does

Remote development, not remote desktop.

SRDA focuses on practical, permissioned development workflows. General mouse, keyboard and screen control are not its current objective.

Inspect and edit projects

Read source, search approved folders, write scoped files and recover earlier versions through backups.

Build Windows applications

Run selected build workflows. SRDA has successfully packaged a Windows desktop application using PyInstaller.

Android debugging

Detect an authorized Android device, launch the supported test app and collect application-specific Logcat diagnostics.

Development scripts

Run supported Python, Flutter and other developer jobs and inspect their status, exit codes and bounded output.

Git integration

Inspect repository changes and use scoped, explicitly authorized commit and push operations. Publishing is never automatic.

Owner-controlled access

Designed for selected projects on the owner's own Windows computer, using authenticated access and Windows user permissions.

Availability and roadmap

Private, operational, still evolving.

M7 is used for real project work. Reliability across disconnections, broader PowerShell execution and further Git workflow verification remain development priorities. There is no public installer, account registration or access offering.

Sanat Relay Desktop Agent is an independent Sanat Utility Studio project. It is not an official OpenAI product.
